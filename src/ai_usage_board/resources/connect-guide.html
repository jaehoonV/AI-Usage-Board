AI Usage Board 연결 안내

카드마다 연결 방법이 다릅니다. 한 번 연결해 두면 위젯을 다시 켜도 그대로 이어집니다.

Codex

  1. Codex 앱이나 npm i -g @openai/codex로 설치한 CLI 중 하나만 있으면 됩니다.
  2. Codex에 이미 로그인해 두었다면 따로 할 일이 없습니다. 카드에 바로 숫자가 나옵니다.
  3. 카드에 계정 연결이 보이면 누르세요. Codex가 쓰는 OpenAI 로그인 페이지가 기본 브라우저에 열립니다.

로그인 정보는 Codex가 직접 관리합니다. 위젯은 Codex에게 남은 한도만 물어봅니다.

Claude · Gemini

  1. 카드의 계정 연결을 누르면 Chrome(없으면 Edge) 창이 하나 뜹니다. 평소 브라우저와 섞이지 않는 위젯 전용 프로필입니다.
  2. 그 창에서 평소처럼 로그인하세요.
  3. 카드로 돌아와 로그인 완료를 누르면 창이 닫히고, 이후로는 보이지 않는 곳에서 사용량 화면만 읽습니다.
  4. 카드에 창 열기가 뜨면 사이트가 사람인지 확인하는 중입니다. 눌러서 확인을 마쳐 주세요.

사용량 화면의 막대와 초기화 시각만 읽습니다. 대화 내용, 계정 정보, 쿠키는 읽지 않습니다. 다른 계정으로 바꾸려면 트레이 메뉴의 Claude 연결 초기화 / Gemini 연결 초기화를 쓰세요.

Antigravity

  1. 할 일이 없습니다. Antigravity에 로그인해 둔 PC라면 카드가 알아서 채워집니다.
  2. 앱이 켜져 있으면 1분마다, 꺼져 있으면 10분마다 모델별 남은 할당량을 확인합니다.

플랜 이름과 모델별 할당량만 가져옵니다. 프로젝트나 대화는 건드리지 않습니다.

화면 읽는 법

  • 숫자는 이미 쓴 비율입니다. 서비스가 토큰 수 대신 비율만 알려 주기 때문입니다.
  • 65% 이상이면 주황, 90% 이상이면 빨강입니다. 10분 넘게 새 값을 못 받으면 회색으로 바뀝니다.
  • 창의 ✕는 트레이로 숨기기입니다. 끄려면 왼쪽 아래 설정 메뉴나 트레이 메뉴의 종료를 누르세요.
  • 설정 메뉴에서 작업 표시줄 위에 한 줄짜리 막대를 따로 켤 수 있습니다.
